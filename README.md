# Young - Tours & Travels

Welcome to the Young Tours & Travels project!

This repository contains the frontend application for a premium tours and travel booking platform. It features a modern, responsive design built with HTML, CSS, and potentially React/Vite in the future.

## Features (Current Prototype)
- **Glassmorphism Design:** A beautiful, frosted-glass sticky navigation bar that adapts to scrolling.
- **Immersive Hero Section:** High-quality background imagery with a clear call-to-action search bar.
- **Dynamic Micro-animations:** Subtle hover effects on destination cards for an engaging user experience.
- **Responsive Layout:** Designed to look stunning on both desktop and mobile screens.

## Getting Started

To view the current frontend prototype:

1. Clone the repository:
   ```bash
   git clone https://github.com/utkarshdaule11/Travel-Web-.git
   ```
2. Open the `frontend/index.html` file in your preferred web browser. No installation or build process is required for this initial prototype.

## Technologies Used
- HTML5
- CSS3 (with CSS Variables for theming)
- Google Fonts (Inter)
